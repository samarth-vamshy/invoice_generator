# Invoice Generator for Teams

This project keeps its own Microsoft Teams SDK bot, Bot Framework registration, `src/app.py` entry point, and `/api/messages` endpoint. The invoice workflow is registered on that active `App` by `src/invoice_routes.py`.

## Features

- Home card: Generate Invoices, Search Invoices, and Help.
- Generate Random: choose a count and purpose; create distinct companies, amounts, invoice numbers, and PDFs.
- Customize: enter seller and buyer names, addresses, tax IDs, dates, tax type/rate, amount range, line item mode, and count. Review shows the exact entered details. A custom batch keeps company details, tax settings, invoice date, and line descriptions fixed while invoice numbers and amounts vary.
- Generate on the Review card is the only action that creates PDFs. Edit and Cancel never generate.
- Each PDF is uploaded to the SharePoint Invoice Library. A result counts as stored only after required metadata is verified. Failed metadata writes trigger cleanup of the uploaded file.
- Search reads Invoice Library metadata by invoice number, batch, purpose, date, or text. Unrelated questions use the existing Teams SDK Azure OpenAI chat path.

Adaptive Card buttons use `Action.Execute` with deterministic `action` and `verb` identifiers. `src/invoice_routes.py` handles their `adaptiveCard/action` invokes and logs the activity type, action, route, and response type.

## Configuration

The project's existing bot and Azure OpenAI settings remain in its local `.env`. Invoice storage additionally uses `SHAREPOINT_SITE_ID`, `SHAREPOINT_LIBRARY_ID`, `SHAREPOINT_LIBRARY_NAME`, `SHAREPOINT_GRAPH_TENANT_ID`, `SHAREPOINT_GRAPH_CLIENT_ID`, `SHAREPOINT_GRAPH_CLIENT_SECRET`. These have been copied locally from the previous working invoice project without changing this project's bot credentials. Keep `.env` and `env/.env.*.user` out of source control.

The Graph app needs access to the existing site and Invoice Library. With `Sites.Selected`, grant the application permission and an explicit write grant on the site. The `Generated By` column must be a real single-value Person field. The agent resolves the current user against the SharePoint site's user list; if the user cannot be resolved, invoice generation stops before upload. The agent does not grant permissions or create the library.

The existing Azure template now passes these invoice settings to App Service from `env/.env.dev.user`. This project's `m365agents.local.yml`, `m365agents.playground.yml`, and Teams manifest were not replaced by files from the previous repository.

## Run and verify

Use this project's **Debug in Teams** configuration to start its bot and tunnel. Send `Hi`, then follow Generate Invoices → Generate Random or Customize → Review → Generate. Search and Help are available from Home. Run `python -m unittest discover -s tests -v` for the local calculation, routing, PDF, and SharePoint boundary tests. A real SharePoint upload requires the Graph permission and site grant to be active.
